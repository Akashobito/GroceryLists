# Grocery List App (React + localStorage)

A responsive React grocery list app that stores items in the browser’s **localStorage**, so your list persists even after page reloads. Users can add, edit, mark items as done, and delete groceries with a clean UI, auto-scroll behavior, and automatic input capitalization for better readability.

## Features
- Add grocery items
- Edit existing items
- Mark items as completed (check off)
- Delete items
- Persistent storage using `localStorage` (data survives refresh/reload)
- Auto-scroll to latest item/action for smoother UX
- Input capitalization/formatting for cleaner list text
- Responsive design (mobile + desktop)

## Built With
- React.js
- Browser `localStorage`
